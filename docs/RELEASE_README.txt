Maple PiP Manager v0.9.0-beta — 처음 실행하기
================================================

1. 이 ZIP을 원하는 폴더에 "전체 압축 해제"합니다.
2. 압축을 푼 폴더 안의 CropPipViewer.exe를 실행합니다.
3. MapleStory를 실행한 뒤 프로그램에서 대상 창을 선택합니다.

[중요]
- .NET Runtime을 별도로 설치할 필요가 없습니다.
- .NET Desktop Runtime을 별도로 설치할 필요가 없습니다.
- .NET SDK를 설치할 필요가 없습니다.
- 실행에 필요한 .NET 8 런타임은 이 배포 폴더에 포함되어 있습니다.
- EXE만 따로 빼서 실행하지 말고, 압축 해제된 폴더의 파일들을 함께 유지하세요.
- ZIP 안에서 EXE를 직접 실행하지 말고 반드시 먼저 전체 압축 해제하세요.

[지원 환경]
- Windows 10 2004(빌드 19041) 이상 x64
- Windows 11 x64

[Windows SmartScreen]
코드 서명이 없는 Beta 프로그램이므로 Windows에서 SmartScreen 경고가 표시될 수 있습니다.
이는 .NET 런타임 누락과는 별개의 Windows 보안 경고입니다.
공식 GitHub Release의 ZIP 및 SHA-256 값과 대조해 배포 파일을 확인할 수 있습니다.

[설정/로그]
%APPDATA%\CropPipViewer

자세한 사용법은 USER_GUIDE.md와 README.md를 참고하세요.


[배포 파일 구조]
압축을 풀면 최상단에는 CropPipViewer.exe와 docs 폴더만 있습니다.
프로그램 실행은 CropPipViewer.exe를 더블클릭하세요.
.NET Runtime/SDK는 별도로 설치할 필요가 없습니다.
