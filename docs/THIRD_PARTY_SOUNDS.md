# Third-party READY notification sounds

Maple PiP Manager v0.9.7-beta packages the following notification sound files for the burst cooldown READY alert presets.

All three source recordings are marked **Public Domain** on Wikimedia Commons. The release build downloads the Commons MP3 transcodes and packages them locally under `assets/sounds`, so playback does not require an internet connection.

## Doorbell

- Packaged file: `assets/sounds/doorbell.mp3`
- Source: Wikimedia Commons, **Doorbell-cheap-dingdong.ogg**
- Author/uploader: Dub
- License: Public Domain
- Source page: https://commons.wikimedia.org/wiki/File:Doorbell-cheap-dingdong.ogg

## Dog bark

- Packaged file: `assets/sounds/dog-bark.mp3`
- Source: Wikimedia Commons, **George vuf 1996.ogg**
- Author: Broadbeer
- License: Public Domain
- Source page: https://commons.wikimedia.org/wiki/File:George_vuf_1996.ogg

## Rooster

- Packaged file: `assets/sounds/rooster.mp3`

- License: Public Domain

## Voice preset

The `AI 음성` preset does not bundle a third-party recording. It uses the Windows-installed SAPI text-to-speech voice at runtime and speaks one of:

- `준극딜 돌았습니다`
- `극딜 돌았습니다`
- `오리진 돌았습니다`

The exact voice depends on the voices installed and selected by Windows.
