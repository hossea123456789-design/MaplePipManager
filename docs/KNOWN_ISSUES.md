# 알려진 문제 / Beta 안내

## 극딜 자동 감지
현재 가장 실험적인 기능입니다.

- 쿨이 끝난 직후 매우 빠르게 재사용하는 상황에서 감지가 누락될 수 있습니다.
- 보스방 이동 등 게임 자체의 강제 쿨 초기화 상황은 일반 쿨 흐름과 다르므로 추가 검증이 필요합니다.
- 스킬 아이콘/해상도/UI 배율이 학습 시점과 달라지면 재학습이 필요할 수 있습니다.
- 감지 결과가 `불확실`인 경우 억지로 사용/준비 상태를 확정하지 않습니다.

첫 공개판에서는 이 기능을 **Beta 기능**으로 안내하는 것을 권장합니다.

## Windows SmartScreen
코드 서명이 없는 개인 개발 프로그램은 Windows SmartScreen에서 경고가 나타날 수 있습니다. GitHub Release 파일의 SHA-256을 함께 제공하고, 사용자가 GitHub 소스를 직접 확인할 수 있도록 공개하는 방식을 권장합니다.
