# 사용자 가이드

## 1. 처음 실행
공식 GitHub Release의 `win-x64` ZIP은 .NET 8 self-contained 배포이므로 일반 사용자가 .NET Runtime이나 SDK를 따로 설치할 필요가 없습니다.

1. Release ZIP을 원하는 폴더에 **전체 압축 해제**합니다.
2. MapleStory를 먼저 실행합니다.
3. 압축 해제된 폴더에서 `CropPipViewer.exe`를 실행합니다.
4. 상단 `새로고침`을 누릅니다.
5. MapleStory 창을 선택한 뒤 `대상 선택`을 누릅니다.

> `CropPipViewer.exe`만 다른 곳으로 따로 빼지 말고 배포 폴더의 파일들을 함께 유지하세요.

## 2. 크롭 추가
1. `크롭 추가`를 누릅니다.
2. 필요한 게임 UI 영역을 선택합니다.
3. 생성된 크롭은 PiP에서 위치/크기/회전을 조절할 수 있습니다.

## 3. 프리셋
- 프리셋은 최대 6개입니다.
- 현재 구성을 보존하려면 `현재 설정 저장`을 사용합니다.
- 프리셋 최초 저장 시 연결된 MapleStory 해상도를 기준 해상도로 저장합니다.
- v0.9.1-beta부터 `창 크기 연동` 기능은 프리셋 전환 시 크롭 표시 크기가 누적 변형될 수 있어 제거되었습니다.

## 4. 투명도
- `선택 PIP 크롭 투명도`: 선택한 PIP만 변경
- `크롭 투명도 전체 적용`: 모든 PIP 일괄 변경
- `선택 PIP 배경 투명도`: 선택 PIP의 배경만 변경
- `PIP 배경 전체 적용`: 모든 PIP 배경 일괄 변경

## 5. 크롭 테두리
- 크롭 목록에서 대상을 선택합니다.
- `크롭 테두리 스타일`에서 팔레트 색과 투명도를 지정합니다.
- 스타일 복사/붙여넣기를 지원합니다.

## 6. 전투 중 사용
- PIP 배치가 끝나면 `PIP 클릭 무시`를 사용하는 것을 권장합니다.
- 일반 PIP를 숨기면 극딜 감지 PIP도 함께 숨겨집니다.
- `메이플 활성 시만 PIP 표시`를 켜면 MapleStory 또는 Maple PiP Manager가 활성화되어 있을 때만 PIP가 보입니다.
- Chrome/Discord/탐색기 등 다른 프로그램으로 전환하면 PIP가 자동으로 숨겨지고, 메이플로 돌아오면 자동 복원됩니다.
- `항상 위`와 함께 사용하면 메이플에서는 PIP가 위에 유지되면서 다른 앱 위에는 남지 않게 사용할 수 있습니다.

## 7. 극딜 감지(Beta)
- 준극딜 / 극딜 / 오리진 역할의 크롭을 지정합니다.
- 준비 상태와 사용 직후 상태를 각각 학습합니다.
- 역할별 실제 스킬키를 등록할 수 있습니다.
- 키 입력만으로 사용을 확정하지 않고 화면 변화까지 함께 검증합니다.
- 역할별 감지 지연 보정값(예: 1.5초)을 입력할 수 있습니다.
- 임박 알림 기준은 설정 가능한 초 값입니다.

## 8. 업데이트
v0.9.1-beta부터 상단 `업데이트 확인` 버튼을 사용할 수 있습니다.

- 프로그램 시작 후 GitHub Release를 자동 확인합니다.
- 최신 버전을 사용 중이면 별도 팝업을 띄우지 않습니다.
- 새 버전이 있으면 상단 버튼이 `업데이트 <버전>` 형태로 바뀌고 상태 표시줄에도 안내가 나타납니다.
- 버튼을 눌러 승인하면 최신 `win-x64` ZIP을 자동 다운로드합니다.
- Release에 SHA-256 체크섬이 있으면 다운로드 파일을 검증합니다.
- ZIP을 임시 폴더에 자동 압축 해제한 뒤 현재 프로그램을 종료하고 파일을 교체한 다음 새 버전을 다시 실행합니다.
- 프리셋/설정은 `%APPDATA%\CropPipViewer`에 있으므로 업데이트해도 유지됩니다.

프로그램을 쓰기 권한이 없는 시스템 폴더에 둔 경우 자동 파일 교체가 제한될 수 있습니다. 이 경우 일반 사용자 폴더로 옮기거나 GitHub Release ZIP으로 수동 업데이트하세요.

## 9. 설정 초기화/삭제
설정 파일은 `%APPDATA%\CropPipViewer`에 있습니다. 프로그램을 종료한 뒤 해당 폴더를 백업/삭제하면 설정을 초기화할 수 있습니다.
